# AiShell Documentation

Welcome to the AiShell platform documentation.

## Architecture & Evolution
AiShell evolves over 10 milestones:
1. **Week 1:** Buildable baseline & CLI utility (`sysinfo`)
2. **Week 2–9:** Builtins, process execution (`fork`/`exec`), pipes, signals, threads, sockets
3. **Week 10:** Natural language interface and confirmation gate

## Command Index
- [`sysinfo`](commands/sysinfo.md) - Display OS kernel, release, hostname, and machine architecture.
